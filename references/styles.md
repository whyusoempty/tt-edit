# Как собрать пять стилей под трек

Стиль — это не название игры, а сочетание значений по осям. Список стилей не фиксирован: каждый раз собирай пять заново из осей ниже под конкретный текст и звук. Реальные игры — только как ориентир эстетики «в духе», без их ассетов, персонажей и сцен.

## 1. Прочитай трек

Выпиши для себя (пользователю не показывай):

**Из текста**
- Образы и предметы, которые можно показать: часы, телефон, дверь, канал, круг, окно, машина, море… Каждый — потенциальный носитель текста или событие.
- Места и время суток (явные и подразумеваемые): «пять утра» → предрассветный свет, пустые улицы, бессонница.
- От чьего лица: «я» → первое лицо или герой в кадре; «ты» → второй персонаж/экран/отсутствие; «мы» → группа.
- Настроение и его движение по строкам: тревога → апатия → вопрос; эйфория → спад.
- Повторы и рефрен: повтор просит петлю, цикл, тот же кадр с изменением.
- Плотность: сколько слов в секунду. Плотно (>3 слова/с) → короткие строки в UI или крупные надписи по одной; редко → можно дать камере дойти до носителя.

**Из `timing.json`**
- BPM и доля: темп шагов, частота склеек, мигания. Медленно (<90) — плывущая камера, длинные планы. Средне (90–130) — шаг на долю, склейки по фразам. Быстро (>130) — шаг на долю или полдоли, вспышки на бочках, допускаются резкие смены.
- Паузы вокала: место для блэкаута, тишины, разворота, «что-то изменилось».
- Пик энергии: самое сильное событие сценария.
- Секции: границы = смены локаций/уровней/кадров.
- Звучание — **подтверждённое пользователем** в шаге 4 (см. ниже, как его угадать). Жанр и тембр подсказывают эпоху и платформу (таблица «Звучание → стиль»).
- Формат: 9:16 любит вертикальные композиции (телефон в руке, лестницы, лифты, узкие коридоры, вид сверху вниз), 16:9 — панорамы, сайд-скроллер, гонки, 1:1 — универсален.

## Как угадать звучание

У модели нет слуха: только `timing.json → sound` (+ BPM и текст). Сложи догадку из признаков, потом обязательно дай пользователю поправить.

| Признаки в `sound.summary` | Скорее всего |
| --- | --- |
| мощный саб-бас + half-time (BPM 130–160 без прямой бочки) + минор | трэп, эмо-рэп, клауд-рэп, дрилл (если хэты очень частые и «скользящий» бас) |
| то же + тёмный + частые хэты + перегруз | фонк (дрифт-фонк, мемфис) |
| прямая бочка + яркий + широкая стереобаза | хаус, техно, гиперпоп, дэнс-поп |
| прямая бочка + BPM 80–118 + мажор/минор + синты | синтвейв, ретровейв, диско, нью-вейв |
| срезанный верх + мелодичный + BPM 60–95 | лоу-фай, чилл, бедрум-поп |
| шумный/перегруженный + яркий + барабаны впереди | рок, панк, метал, пост-панк, шугейз (если ещё и широкий и тёмный) |
| мелодичный, мало ударных + большая динамика | баллада, акустика, эмбиент, саундтрек |
| BPM 160–180 + частые хэты + плотный низ | драм-н-бейс, джангл, брейкс |
| вокал впереди + умеренный темп + яркий | поп, R&B |

Русский текст не значит русский жанр: язык не меняет звучание. Если признаки противоречат — выбери по тексту и темпу, а альтернативы покрывают остальное. Лад: минор — чаще тревога и грусть, мажор — свет, дерзость, ирония (грустный текст на мажоре — сильный контраст для стиля).

## 2. Оси стиля

Комбинируй значения. Ниже — стартовые варианты, не исчерпывающий список: добавляй свои, если трек просит.

| Ось | Значения (примеры) |
| --- | --- |
| Эпоха / техника рендера | 8-бит 2D, 16-бит пиксель-арт, 2.5D рейкастер начала 90-х, PS1 (дрожащие вершины, аффинные текстуры, дизеринг), N64/ранний 3D с мягким фильтром, PS2/ранние 2000-е, VHS/found footage, современный инди low-poly, фотореал, NPR (карандаш, тушь, гравюра, акварель, пластилин-подобный), CRT-терминал / текстовый квест, FMV, UI-only (рабочий стол, телефон, браузер) |
| Камера | первое лицо (идёт/сидит/лежит), фиксированные ракурсы старой игры, третье лицо за плечом, изометрия/сверху, сайд-скроллер, экран-в-экране (CCTV, монитор), статичный кадр с анимацией внутри |

## 3. Отбор пятёрки

1. Набросай 8–12 кандидатов-сочетаний.
2. Оцени каждого по трём вопросам: (а) за какой конкретной строкой стоит его главный образ; (б) какую особенность музыки он отыгрывает (темп камеры, пауза, пик, тембр); (в) как в нём естественно живёт текст. Нет ответа хотя бы на один — выкидывай.
3. Оставь пять так, чтобы любые два различались минимум по двум осям (не «PS1 квартира» и «PS1 подъезд»).
4. Состав: 1–2 «очевидно в тему», 2 сильные альтернативы, 1 неожиданный, но обоснованный (другая эпоха или жанр, который неожиданно ложится на текст).
5. Убери стили, уже сделанные в соседних папках (прочитай их `README.md`), если пользователь не просит повторить.
6. Учти цену: стиль, которому нужен Blender или 15+ источников света, пометь «тяжёлый», но не выкидывай из-за этого.

Не своди стиль к хоррору по умолчанию. Хоррор уместен, когда текст про тревогу, бессонницу, потерянность. Для лёгкого/влюблённого/дерзкого трека ищи гонки, платформеры, RPG, визуальные новеллы, симуляторы, ритм-игры.

## 4. Как показать

Сообщением, нумерованно 1–5. Для каждого 3–5 коротких строк:

```
**2. Ночной переход-петля** — фотореал, первое лицо, кафельный коридор под лампами.
Почему: «как мне выйти с этого круга» → бесконечный цикл с аномалиями; 143 BPM → шаг на каждую долю, лампы гаснут по бочкам.
Текст: естественно в мире (указатели, плакаты, табло). Blender не нужен. Рендер тяжёлый (~5 мин на 30 с).
```

В конце: «Выбери номер — или скажи, что смешать/поменять». Если пользователь смешивает стили — собери гибрид и коротко опиши его одной строкой, без повторного опроса.

## 5. Пример: что выходило на одном треке

Трек о бессоннице в 5 утра (143.5 BPM, пауза вокала, пик ближе к концу) — семь разных роликов, все работали:

| Стиль | Камера | Текст | Техника |
| --- | --- | --- | --- |
| PS1 survival horror, коридор-петля и комната | первое лицо с фонарём | микс: краска на стенах + диалоговые окна | Three.js, 375² ×4, дизеринг |
| Психологический хоррор от первого лица, квартира ночью, VHS | один непрерывный проход | UI: субтитры рассказчика, `[E]`-подсказки, телефон | Three.js PBR, тени, VHS-пост |
| Shareware-шутер 1994, телефон вместо оружия | первое лицо, статус-бар | UI: сообщения игры, экран телефона, межуровневый экран | Canvas 2D рейкастер, палитра LUT |
| PS1, туманный город, двойник героя | фиксированные ракурсы от третьего лица | UI: игровые текстовые окна + карта | Three.js, аффинные текстуры |
| PSX-психохоррор на корабле | первое лицо, CCTV | микс: терминалы и мониторы + диалог с подписью говорящего | Blender → GLB, запечённый AO |
| Liminal «найди аномалию», белый переход метро | первое лицо, три цикла | мир: постеры, указатели, наклейки, табло | Three.js фотореал, RectAreaLight, fisheye |
| Фольклорный хоррор карандашом, горная деревня | первое лицо, наплывы | мир: таблички, резьба, вышивка, записки | Three.js + NPR-пост «карандаш» |
