# NO EXIT // 05:00

Сниппет в эстетике PS1 survival horror под трек `assets/track.mp3` (26.68 с, 143.5 BPM).
HyperFrames + Three.js 0.181 + GSAP. Формат 1500×1500, 30 fps.

## Файлы

| Путь | Что это |
| --- | --- |
| `index.html` | Корневая композиция: аудио + два слоя (мир и HUD) |
| `compositions/world.html` | 3D-мир Three.js: коридор-петля, комната, свет, камера, пост-обработка |
| `compositions/hud.html` | Игровой интерфейс на GSAP: диалоги, окна ошибок, титр зоны, RESTART? |
| `lyrics-timing.json` | Карта синхронизации: строка, слова с таймкодами, объект, действие камеры |
| `transcript/` | Транскрипция: пословные таймкоды, вокал и минус отдельно, скрипт распознавания |
| `assets/fonts/PressStart2P.ttf` | Пиксельный шрифт с кириллицей (OFL) |
| `renders/NO-EXIT-0500.mp4` | Готовое видео |

## Как устроено изображение

- Мир рендерится в 375×375 и увеличивается ×4 без сглаживания (`image-rendering: pixelated`).
- Вершины привязываются к сетке экрана (дрожание как на PS1), текстуры процедурные 32–96 px с nearest-фильтром.
- Пост-шейдер: 4×4 Bayer-дизеринг в ~26 уровней на канал, зерно, лёгкая хроматическая аберрация, срывы строк VHS на склейках, виньетка, веки.
- Поверх кадра — CRT-сканлайны на той же 4-пиксельной сетке.
- Всё — функция времени: кадр рисуется из `hf-seek`, мерцание ламп считается хешем номера кадра, случайность сидирована.

## Команды

```bash
npx hyperframes preview
npx hyperframes check
npx hyperframes render -q delivery -o renders/raw.mp4
```

Рендерер HyperFrames понижает трек на 3 dB (в исходнике true peak +2.1 dBTP). Чтобы вернуть оригинальную громкость, подменяем звук:

```bash
ffmpeg -i renders/raw.mp4 -i assets/track.mp3 -map 0:v -map 1:a -c:v copy -c:a aac -b:a 320k -t 26.68 -movflags +faststart renders/NO-EXIT-0500.mp4
```
