# ГОРОД, КОТОРОГО НЕТ / THE TOWN THAT ISN'T THERE

Четвёртый lyric video на тот же трек: PS1 survival horror с камерой от третьего лица, туманный город и двойник героя. Предыдущие проекты (`../`, `../ftf`, `../doom`) не тронуты.

Готовое видео: `renders/GOROD-KOTOROGO-NET.mp4` (1500×1500, 30 fps, 801 кадр, оригинальный звук).
Режиссёрская карта по таймкодам: `DIRECTION.md`.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Корневая композиция: мир, текстовые окна, трек |
| `compositions/world.html` | Three.js: весь город, герой, двойник, силуэты, камеры, свет, туман, экран карты, телефон, часы, PS1-постобработка |
| `compositions/hud.html` | Игровые текстовые окна с лирикой, слово за словом по времени вокала |
| `assets/fonts/PressStart2P.ttf` | Пиксельный шрифт с кириллицей (и для окон, и для вывесок в 3D) |
| `assets/track.mp3` | Копия исходного трека |

Все текстуры, модели и персонаж процедурные: рисуются на Canvas при сборке сцены. Внешних моделей и картинок нет.

## PS1-пайплайн

- Внутреннее разрешение 300×300, увеличение ×5 без сглаживания (`image-rendering: pixelated`). Шрифт 40 px = 5 px на пиксель шрифта, поэтому текст лежит на той же сетке.
- Вершины прилипают к сетке экрана (дрожание геометрии), текстуры частично аффинные (`uv·w / w`), геометрия разбита на куски по ~2 м, чтобы искажение не рвало картинку.
- Текстуры 8–10 px на метр, фильтр nearest. Постобработка: 5-битные каналы с упорядоченным дизерингом Байера 4×4, холодная серо-зелёная гамма, лёгкий шум и строки захвата, слабая хроматическая аберрация.
- Туман линейный и настраивается отдельно для каждого кадра. Плюс низкие клубы-спрайты, конусы и ореолы фонарей.

## Как пересобрать

```bash
npx hyperframes check --json
npx hyperframes snapshot --at 0.5,8.85,13.3,17.0,25.5 --no-end -o snaps/x
npx hyperframes render -q delivery -o renders/raw.mp4
ffmpeg -y -i renders/raw.mp4 -i assets/track.mp3 -map 0:v -map 1:a -c copy -t 26.68 -movflags +faststart renders/GOROD-KOTOROGO-NET.mp4
```

Последний шаг обязателен: рендерер понижает громкость на 3 dB, поэтому звук подменяется исходным MP3-потоком без перекодирования.

## Где что крутить

- Времена склеек: объект `CUT` в начале модуля `world.html`. Ключевые события: `T_PYAT` (05:00), `T_OFF` и `T_ON` (свет в павильоне), `T_SNOV` (исчезает фигура), `T_END` (темнота).
- Путь героя: массив `HERO`, ключи `[время, x, z, поворот, сглаживание]`. Фаза шага считается из пройденного пути, ноги не скользят.
- Позы: `phoneAmt`, `inspectAmt`, `backAmt`, `headAt`.
- Камеры: `camAt` (по кадру). Туман: `fogAt`. Свет фонарей: `lampLevel`.
- Карта: `mapBase` (бумага и улицы), `drawMap` (стрелка «ВЫ ЗДЕСЬ», крестики, петля маршрута).
- Лирика: `hud.html`, атрибут `data-words` («слово@время»), `data-hide` — когда окно закрывается.
