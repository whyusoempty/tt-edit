# 05:00 // DOOMSCROLL

Третий lyric video на тот же трек — пиксельный 2.5D-хоррор от первого лица на движке в духе 1993–94 годов. Первые два проекта (корень папки и `../ftf/`) не тронуты.

Готовое видео: `renders/DOOMSCROLL-0500.mp4` (1500×1500, 30 fps, 26.68 с, оригинальный звук без перекодирования).

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Корневая композиция: игра и трек |
| `compositions/game.html` | Весь движок: рейкастер, текстуры, уровни, камера, телефон-«оружие», статус-бар, лирика, автокарта, межуровневый экран, плавление экрана |
| `DIRECTION.md` | Режиссёрская карта по строкам |
| `assets/fonts/PressStart2P.ttf` | Пиксельный шрифт с кириллицей |
| `snaps/` | Проверочные кадры |

## Как устроен движок

- Canvas 2D, без WebGL и Three.js. Кадр 300×300 считается попиксельно в `Uint32Array`, затем растягивается ×5 через `drawImage` с `imageSmoothingEnabled = false`.
- Стены — отрезки под любым углом. Луч на каждый столбец, несколько попаданий с высотами `zb/zt` и попиксельной глубиной: так работают поднимающаяся дверь, перемычки, таблички и дома выше потолка. Пол и потолок кастуются построчно, потолок двухуровневый (давящий потолок зала), небо — панорама по углу.
- Спрайты — billboard с проверкой глубины. Альфа текселя: 0 — прозрачно, 1 — светится сам (окна, экраны, табло), 255 — освещается миром.
- Свет — точечные источники плюс затухание с расстоянием, ступенями по 1/12 (банды как в старых движках). Каждый пиксель приводится к палитре 193 цветов через LUT 32³.
- Текстуры процедурные: ковры, паркет, побелка, бетон, дерматиновая дверь, фасады панелек (5 вариантов окон), снег, небо, фигуры, кровать.
- Шрифт растеризуется один раз в битмапы 8×10. Текст рисуется блоками 1× или 2× с контуром, поэтому пиксели те же, что у мира.
- Плавление экрана: старый кадр (`cut − 1/30`) кэшируется, столбцы по 2 px падают с разной задержкой.
- Всё считается как функция времени в `hf-seek`, случайность сидирована хешем.

## Как пересобрать

```bash
npx hyperframes check --json
npx hyperframes snapshot --at 1.9,7.1,10,13.4,17.9,20.1,22.5,25.5 --no-end -o snaps/x
npx hyperframes render -q delivery -o renders/raw.mp4
ffmpeg -y -i renders/raw.mp4 -i assets/track.mp3 -map 0:v -map 1:a -c copy -t 26.68 -movflags +faststart renders/DOOMSCROLL-0500.mp4
```

Последний шаг обязателен: рендерер сам понижает громкость. Звук копируется исходным MP3-потоком, MD5 декодированного звука совпадает с `assets/track.mp3`.

## Где что крутить

- Камера: `PATH_A` / `PATH_B` / `PATH_C` (время, x, y, курс в градусах, высота глаз, наклон взгляда); облёт колонны — `ORB`.
- Лирика: массив `MSG` и `GROUPS` (слова на колонне). Телефон — `drawRaisedPhone`.
- События: `HITS` (вспышки урона), `WAVES` (окна гаснут), `SHRINK` (сжатие обзора), стадии фигур — `STAGES` в `buildA` / `buildB`.
