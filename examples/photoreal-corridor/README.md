# ВЫХОД 0

Лирик-видео в духе The Exit 8: бесконечный белый подземный переход японского метро от первого лица.
Строки песни постепенно «прорастают» в окружение: постеры, указатели, наклейки, табло, экраны и разметку на полу.
Ассеты и тексты оригинальные, из игры ничего не скопировано.

1500×1500, 1:1, 30 fps, 26.68 с, исходный звук без изменений.

**Видео:** `renders/VYKHOD-0.mp4`
**Карта сцен и строк по таймкодам:** `DIRECTION.md`

## Состав

- `index.html` — корень: подкомпозиция `#world` и `<audio>` с `assets/track.mp3`.
- `compositions/world.html` — вся сцена на Three.js (r181): коридор, процедурные материалы, все носители текста, человек, камера и постобработка.
- `assets/fonts/` — Noto Sans Bold (кириллица), Yu Gothic Bold/Medium (японские надписи, извлечены из системных `.ttc` через fontTools), Bahnschrift (`Exit`, цифры).

Blender не используется: геометрия коридора — плоскости и боксы, её проще и быстрее строить кодом.

## Технические решения

- **Свет**: 14 потолочных ламп с `RectAreaLight` (LTC) дают правильные блики светильников на глазурованной плитке. Заполняющий свет — PMREM-окружение, снятое с самого коридора (`pmrem.fromScene`); его сила меняется вместе с лампами через `scene.environmentIntensity`.
- **AO без запекания**: затенение в углах и на стыках стен с полом и потолком считается аналитически по расстоянию до стен и пишется в цвета вершин. Плоскости разбиты на ячейки 20–25 см.
- **Плитка**: альбедо, карты нормалей и шероховатости генерируются на canvas одной функцией на пиксель. У каждой плитки свой небольшой наклон, поэтому блики ламп по стене слегка «ломаются», как на настоящей кафельной стене.
- **Текст**: все надписи нарисованы на canvas 1–2K с анизотропией 16. Для каждого носителя заранее готовы все состояния (обычное, строка песни, строка по словам), во время кадра меняется только `material.map`.
- **CCTV на цифровой панели**: вторая камера рисует в `HalfFloat`-таргет 384×216, который сразу используется как текстура квада на экране (без `readPixels`).
- **Пост**: HDR-кадр 1800² с MSAA ×4 → блум (2 прохода гаусса) → бочкообразная дисторсия (fisheye, `uBarrel` 0.11; углы кадра совпадают с углами исходника, центр увеличен в 1.22 раза, поэтому сцена рендерится с запасом 1800 → 1500) → ACES → sRGB → хроматическая аберрация по краям, виньетка, зерно, «веки». Базовый FOV — 74°.
- **Ритм**: шаги камеры привязаны к сетке долей минуса (librosa, 143.55 BPM): голова «приземляется» на каждую долю, покачивание идёт на две доли. Мягкие наезды FOV на ключевых словах («выход», «бошке», «пять», «канал», «царство», «вопрос»), короткая встряска на всплесках аномалии, лампы гаснут ровно по долям.
- **Камера**: ключи «позиция + точка взгляда» переводятся в yaw/pitch и интерполируются монотонным кубическим сплайном Эрмита (без перелётов на остановках). Покачивание шага привязано к пройденному пути.

## Пересборка

```bash
npx hyperframes check --json
npx hyperframes render -q delivery -o renders/raw.mp4
ffmpeg -y -i renders/raw.mp4 -i assets/track.mp3 -map 0:v -map 1:a -c:v copy -c:a copy -t 26.68 -movflags +faststart renders/VYKHOD-0.mp4
```

Звук подменяется исходным MP3 без перекодирования: рендерер HyperFrames сам опускает его на 3 дБ.
