# ПОСЛЕДНЯЯ СМЕНА / 05:00

Лирик-видео в духе PSX-психохоррора (по настроению близко к Mouthwashing, но всё своё: корабль без
названия, свой персонаж, свои текстуры и надписи). 1500×1500, 1:1, 30 fps, 26.68 с, исходный звук.

**Видео:** `renders/POSLEDNYAYA-SMENA-0500.mp4`
**Карта сцен и слов по таймкодам:** `DIRECTION.md`

## Состав

- `index.html` — корень: подкомпозиции `#world` (Three.js) и `#hud` (диалоги), плюс `<audio>`.
- `compositions/world.html` — движок: загрузка GLB, PS1-материалы, экраны на canvas, камеры, постобработка.
- `compositions/hud.html` — диалоговые окна с подписью говорящего и подсказки `[E] ОТКРЫТЬ` / `ЗАПЕРТО`.
- `blender/` — исходники локаций и персонажа (Blender 5.1, только headless bpy):
  - `build_rooms.py <med|corr|ctrl|ring|quarters|crew>` — собирает комнату, запекает AO в цвета вершин, пишет `.blend` и `assets/models/<room>.glb`;
  - `lib.py`, `kit.py`, `kit2.py` — сетка комнат, материалы, UV, запекание, экспорт; набор деталей (двери, пульты, стены мониторов, капсула, шкафчики…);
  - `characters.py` + `headparam.py` + `faces.py` — член экипажа: тело на skin-модификаторе, вылепленная голова, рисованное лицо 512 px, пряди волос, рука с телефоном;
  - `textures.py`, `textures2.py` — все пиксельные текстуры (`assets/tex/`), рисуются numpy/PIL;
  - `build_test.py` — обязательный тест конвейера (коридор → GLB → HyperFrames).
- `assets/models/*.glb` — 6 локаций/персонажей + тестовый коридор.

Пересборка: `python blender/textures.py && python blender/textures2.py && python blender/faces.py`,
затем `blender -b --factory-startup --python blender/build_rooms.py -- <room>` для каждой комнаты,
затем `npx hyperframes render -q delivery -o renders/raw.mp4` и подмена звука (см. ниже).

## Технические решения

- **Blender → GLB → Three.js.** Blender MCP-аддон установлен, но к сессии не подключился, поэтому всё строится скриптами bpy в фоне. GLB грузится `GLTFLoader` из jsdelivr `+esm` и в snapshot, и в render.
- **Свет запечён в AO вершин** (Cycles, `VERTEX_COLORS`), в рантайме — несколько точечных источников на комнату и монохромный градиент по сцене (зелёный / оранжевый / красный / белый).
- **PS1-вид:** внутренний кадр 500×500 с увеличением ×3 без сглаживания, привязка вершин к сетке, частично аффинные UV, дизеринг Байера 4×4, без VHS-мыла.
- **Экраны** — `CanvasTexture` с `flipY = false`; 110 мелких мониторов пульта собраны в один атлас 1024×384.
- **CCTV** — вторая камера рисует в render target 128×96, кадр читается в canvas с гаммой и автоэкспозицией. Фигура «за спиной» видна только этой камере (слой 1).
- **Персонаж:** skin-модификатор + одна ступень subdivision дают гладкое low-poly тело. Голова — сфера с плотной сеткой у лица, нос, скулы, надбровья и челюсть вылеплены гауссовыми бугорками. Лицо — рисованная текстура 512 px в той же параметризации (тяжёлые веки, мешки под глазами, щетина), две версии: глаза закрыты / открыты.
- **Звук:** рендер HyperFrames опускает звук на 3 дБ, поэтому видео собирается заново с исходным MP3 через `-c copy`.
